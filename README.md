# Sistem E-Learning 
Aplikasi pembelajaran digital (*e-learning*) berbasis web untuk SD N 2 Pabuwaran yang dirancang untuk memfasilitasi pengiriman materi pelajaran serta pengumpulan tugas sekolah secara *online*.

 **URL Live Website:** [https://e-learning.sdn2pabuwaran.sch.id/](https://e-learning.sdn2pabuwaran.sch.id/)

---

##  Hak Akses & Fitur Utama

Aplikasi ini mendukung 3 peran pengguna (*roles*):

1. **Admin**
   - Pengelolaan data pengguna (Siswa, Guru, Admin).
   - Pengelolaan kelas dan konfigurasi sistem.
   - Fitur reset password admin berbasis email SMTP.

2. **Guru**
   - Mengunggah dan mengelola materi pembelajaran.
   - Membuat dan membagikan tugas untuk siswa.
   - Memeriksa serta memberikan penilaian terhadap tugas siswa.

3. **Siswa**
   - Mengakses dan mengunduh materi pembelajaran.
   - Mengerjakan serta mengumpulkan tugas sekolah secara *online*.
   - Melihat status pengumpulan dan nilai tugas.

---

##  Teknologi yang Digunakan

- **Backend**: PHP (Native)
- **Database**: MySQL / MariaDB
- **Frontend**: HTML5, CSS3, JavaScript
- **Dependency Manager**: Composer
- **Email Service**: PHPMailer (SMTP Integration)
- **Web Server**: Apache / LiteSpeed (CPanel Hosting)
